# Client configurations

Every example uses region `eu2`. **Substitute your own** — see [Regions](../../docs/regions.md).

All examples use OAuth by default: connect, approve in the browser, done. To use an API key instead, add an `Authorization` header as shown in [`api-key.md`](api-key.md).
